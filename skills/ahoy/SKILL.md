# /ahoy

Recap the visible fleet for the captain. Do not spawn anything.

1. Read `data/fleet.md`, `data/log.md` (last 40 lines), `data/captain.md`.
2. Run `bin/orch-status.sh`.
3. Answer in this order:
   - What changed since last ahoy / session start
   - What is blocked and needs the captain (one question each)
   - What is running and can be ignored
   - What finished and where the artifact lives (`data/reports/…` or worktree branch)
4. If the fleet is empty, say so and ask what to take on.
