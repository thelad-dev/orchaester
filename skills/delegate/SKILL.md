# /delegate

Force the current ask onto the fleet. Use when you feel the urge to "quickly handle it".

1. Classify: `scout` | `ship` | `review` | `local`. `chat` is invalid here — if you invoked /delegate, it is not chat.
2. Split only if the ask names two unrelated deliverables. One spawn per deliverable, same turn.
3. Write a brief that a crewmate can finish without you: done definition, repo/workspace, out of scope.
4. `bin/orch-spawn.sh ...`
5. Reply to the captain with ids only. Do not preview how you would have done the work.
