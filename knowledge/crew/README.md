# Crew knowledge

Standing memory for the orchestra — inspired by durable crew records
(charter per role, facts not transcripts). The conductor reads this
before spawning. Crewmates may append a lesson; they may not rewrite
the charter.

| file | who writes | what |
|---|---|---|
| `charters.md` | captain / conductor | persistent roles |
| `lessons.md` | crewmates on done | what actually worked |
| `models.md` | conductor | live notes on quota, which model lied last week |
| `workspaces.md` | conductor | pointers into `config/workspaces.toml` |

Do not paste secrets. Do not dump pane transcripts. One lesson = one dated bullet.
